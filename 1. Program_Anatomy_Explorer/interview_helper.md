# Interview Helper

## What happens when a program runs?
Compiled → Linked → Executable → OS loads → Process created → Memory setup → Execution begins.

## Stack vs Heap
Stack handles function calls and local variables with automatic management.
Heap is for dynamic allocation with flexible lifetime.

## What is a process?
A process is an isolated execution environment with its own memory and resources.

## What is a stack frame?
A stack frame contains function parameters, local variables, and return address.

## Why can recursion be dangerous?
Deep recursion can cause stack overflow.

## Why are locals faster than heap?
Stack allocation is simple pointer movement; heap involves allocator overhead.
